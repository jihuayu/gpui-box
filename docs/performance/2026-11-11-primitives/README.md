# Decorated quad evidence

This freezes the [decorated quad stage](../../RETAINED_DECORATED_QUADS.md).
`validation.json` contains 66 passing hardware pixel scenarios. `metadata.json`
records checked source hashes and build identity; `adapter.json` identifies the
device. Five `primitive-*.png` images preserve the new comparisons.

Color-only update uploads one 160-byte instance. Decoration changes are explicitly
paint-only and use no layout. Existing suite timing controls are not a dedicated
decorated-quad benchmark, and no throughput improvement is inferred from them.

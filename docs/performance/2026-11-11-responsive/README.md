# Responsive contract evidence

This freezes the [responsive stage](../../RETAINED_RESPONSIVE_CONTRACT.md).
`validation.json` includes 61 successful pixel scenarios; `metadata.json` and
`adapter.json` identify the measured source/build and GPU. Seven `responsive-*.png`
images preserve this stage's new cases. Source hashes were checked before copying.

The suite's existing damage/cache timing controls also ran, but they do not
establish a performance improvement for responsive rule resolution. CSS layout
qualification and native presentation remain separate acceptance work.

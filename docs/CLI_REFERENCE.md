## Commands

### `sdk cache add SDK --cache PATH`

Verify and copy a local SDK into a content-addressed cache.

| Contract | Behavior |
| --- | --- |
| Result | CacheReceipt v1 with created/reused state and exact manifest |
| Effects | Verify source, acquire OS writer lock, sync exclusive staging and publish a verified directory. Interrupted staging is retained |
| Offline | Local SDK only. No child tools or network. Cache must be outside source and use unlinked user-owned directories |
| JSON | Supported |

## Compatibility and execution contract

Project configuration uses gpui-box.json v1 and service schema v1. Project values take precedence over built-in optional-field defaults. Local overlays and installation-lock overrides are unsupported. config schema exports structural editor validation. config validate uses the same semantic validator as generation and workflows and reports exact source bytes plus normalized defaults. Schema migrations require an explicit future version contract.

Append --json once anywhere in a finite command. Stdout contains one schema-v1 envelope with cli_version, upstream_revision, command, success, result and error. Human diagnostics and child output use stderr. Exit status is zero on success and nonzero on failure. error has code/message and optional details. dev/logs reject JSON before starting work.

new/init default to starter-v1 and both desktop/android targets. --targets also accepts desktop or android alone. Options take values and repeated options fail. Relative paths resolve against the current working directory. Project workflows read gpui-box.json there.

generate --plan accepts the bare result object from generate --dry-run --json, bounded to1MiB. Apply recomputes current inputs under its lock. Conflicts retain current files and recovery state. Saved plans contain snapshot preconditions.

Android min/native/target API is35 and compileSdk is36. --device SERIAL applies to Android device selection for dev/install/logs. Build/package carry the Android serial environment without installing. Desktop workflows build/run on the current host. info target-family labels describe project scope. Operation qualification is documented separately.

Commands use noninteractive defaults. An ambiguous Android device selection fails with guidance. The CLI has no global offline option. Read-only plans and source SDK operations work from local content. Builds follow inherited Cargo/mise/Gradle resolution and cache policies. Signing inputs stay in the documented GPUI_BOX_ANDROID_* variables and GPUI_BOX_BUNDLETOOL.

SDK SHA-256 verification checks integrity against its supplied manifest. Use a trusted source and delivery channel for authenticity. Available original license texts and unresolved source reviews are tracked in tooling/licenses. Native CLI publication and authenticated SDK download remain roadmap gates.

Build completion, package inspection, device installation and interactive runtime are separate observations. Current generated channels use development. Release-channel provisioning, updates, native installers and broader platform qualification follow their own milestone gates. Physical-device testing remains deferred.

Recovery and onboarding are documented in docs/M3_DEVELOPER_WORKFLOW.md. Packaging/signing use docs/M4_ANDROID_PACKAGING.md. External template CI records CLI/SDK/source/upstream versions, host/targets, commands and artifact digests independently from runtime evidence.

## Stable error codes

| Code | Meaning |
| --- | --- |
| `SDK_CACHE_FAILED` | SDK cache identity, integrity, path, writer locking or publication failed. Existing entries and interrupted staging are preserved |
| `CONFIG_VALIDATION_FAILED` | Project configuration is unavailable, exceeds 1 MiB or fails project/service validation |
| `PLATFORM_ADDITION_FAILED` | Platform addition failed validation, ownership, locking or publication. Retry after reviewing the documented recovery boundary |
| `PLATFORM_QUERY_FAILED` | The optional project configuration could not be read or validated for platform inventory |
| `REGISTRY_QUERY_FAILED` | Bundled registry validation failed or the requested item is unknown |
| `REGISTRY_RESOLUTION_FAILED` | Registry identity, metadata or dependency closure is incompatible, missing or cyclic |
| `REFERENCE_FAILED` | Built-in command reference serialization failed |
| `INVALID_ARGUMENTS` | Unknown command, missing/invalid/repeated option or repeated --json |
| `CURRENT_DIRECTORY_UNAVAILABLE` | The current working directory cannot be resolved |
| `STREAMING_JSON_UNSUPPORTED` | dev/logs requested a finite JSON response |
| `DISTRIBUTION_UNAVAILABLE` | The new/init distribution path cannot be opened |
| `PROJECT_CREATION_FAILED` | new failed validation, staging or publication |
| `PROJECT_INITIALIZATION_FAILED` | init failed validation, ownership, staging or publication |
| `SDK_EXPORT_FAILED` | Committed source closure could not be exported |
| `SDK_VERIFICATION_FAILED` | SDK manifest, paths, source identity or digests failed verification |
| `GENERATION_FAILED` | Generation/apply failed validation, snapshot checks, ownership or file operations |
| `GENERATION_PLAN_FAILED` | Read-only generation preview failed |
| `BUILD_PLAN_FAILED` | Read-only build preview failed or target is disabled |
| `DIAGNOSTICS_FAILED` | Doctor failed to inspect or required checks failed. Completed reports use error.details |
| `DEVICE_QUERY_FAILED` | adb device inventory failed or returned invalid output |
| `WORKFLOW_FAILED` | Build/dev/install/debug-package workflow failed |
| `PACKAGING_FAILED` | Signed Android or Windows portable packaging failed |
| `LOG_STREAM_FAILED` | Human adb log stream failed |

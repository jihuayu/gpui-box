# Bundled font

`NotoSansSC-Regular.otf` is the unmodified Noto Sans CJK SC Regular font from
`notofonts/noto-cjk`, `Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf`.
Its internal family name is `Noto Sans CJK SC`. It is redistributed under the
SIL Open Font License 1.1 in `OFL.txt`.

SHA256 is `2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`.

The full font is bundled to make Latin and Simplified Chinese rendering
independent of device-installed fonts. It adds approximately 16 MB to each
native library before compression. Font subsetting and size optimization are
later packaging work.

[Font source](https://github.com/notofonts/noto-cjk/blob/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf)
